# 七年级数学 Round 路由 Rubric（bootstrap 草案）

状态：`Stage 0 / candidate / 未经 Famin 校准`。本文件只用于生成候选判断和抽审材料，不授权写回题库。七年级不能继承六年级的已校准状态；G6 V4 的验证结论只对其原锚点范围成立。

## 1. 相对难度定义

Round 是“对已完成对应七年级课程的学生而言”的相对认知负荷，不是试卷题号、分值或绝对竞赛难度。

| Round | 七年级相对标准 | 典型信号 |
|---|---|---|
| R1 | 单知识点直接识记或一步执行 | 定义辨认、符号读写、一次直接代入；错项明显 |
| R2 | 两到三步但路径显式 | 语言条件转方程、一次整体代入、简单图形关系后计算 |
| R3 | 至少一次非显式转换，或图文/代数多表征联合 | 数轴判符号后去绝对值、折叠关系转角方程、分段图象解释 |
| R4 | 多次思维转换、强条件耦合或完整分类 | 新定义+递推+周期、大型几何追角、多情形动点/折叠、全局约束构造 |

R4 不是“数字大”或“题面长”；R1 也不等于“选择题”。计算量、图像和题型只作为证据维度，不能单独决定档位。

## 2. 七年级专用证据维度

### 2.1 解题链 `steps`

- 1：直接识记、直接读数或一次代入。
- 2：建立一个关系并计算，或连续两次显式变形。
- 3：三个依赖步骤，且后一步依赖前一步中间量。
- 4：四步以上，或步骤间有两次以上非直接转换。

解答文本很长不自动增加步骤；同一种机械计算重复多次只按一类步骤计。

### 2.2 新颖性与思维转换 `novelty`

重点识别七年级常见高负荷信号：新定义、递推/周期、动态点、折叠、存在性、最大最小、规律探究。只有当这些词确实改变解题路径时才升档，不能关键词命中即定档。

### 2.3 表征联合 `representations`

区分“图只是给数据”和“必须在图、表、数轴、函数关系与代数式间转换”。单幅简单图不升档；两种以上表征相互制约可作为 R3/R4 信号。

### 2.4 情形分支 `branching`

- 无分支：单一路径。
- 一次分支：正负、位置或方向有两种可能。
- 多分支：必须证明覆盖所有情形，或答案含多个有效结果。

“若”只是普通条件时不应误计为分支。bootstrap 工具只能做粗略识别，因此相关结果默认 `review`。

### 2.5 解题路径 KP 跨度 `kp_span`

按解题实际需要的知识族计，不按题面出现的名词计。七上主要知识族包括有理数、整式、方程、几何图形、统计；七下还包括平行线、三角形、轴对称、变量关系、概率。跨两个知识族通常至少 R2/R3，跨三个以上仅是升档证据之一。

### 2.6 计算表达负荷 `calculation`

分数、符号、多个括号和长式变形会增加执行负荷，但不得把机械长算直接判 R4。若思路直接、只有重复运算，应设置上限 R2/R3 并交人工确认。

## 3. 降档与升档保护

降档保护：

- 定义直背、科学记数法直接改写、相反数/系数/次数等一步题优先 R1。
- 题面长但有效条件少，不因阅读长度升档。
- 图像仅装饰或直接读数，不因“如图”升档。
- 多个同类小计算不等于多次思维转换。

升档保护：

- 新定义必须先翻译，再列式，再求解：至少检查 R3。
- 动点/折叠/平行/函数图象同时出现：检查 R3–R4。
- 递推+周期+大下标定位：检查 R4。
- 两种以上有效答案且需证明分类完整：检查 R4。

## 4. Anchor 使用规则

`g7_math_anchor_candidates.json` 中当前所有条目都是候选：

1. 候选锚点只能显示“最近候选”和相似度，不能覆盖 rubric 结果。
2. 候选存在时，结果仍必须标记 `review`。
3. 只有 Famin 在抽审稿中确认后，才可把对应条目标为 `confirmed_by_famin`，并记录确认档、评语和日期。
4. 确认锚点与 rubric 相差两档以上时必须 `review`，不得自动向锚点吸附。
5. 图片依赖题只有在原图可见且题图绑定已核时，才能成为正式锚点。

## 5. 从 Stage 0 升级

- Stage 0 → Stage 1：每档至少 3 个跨 KP 的 Famin 确认锚点；R1–R4 均覆盖；对一批未参与选锚的题完成抽审，并记录一致率与主要偏差模式。
- Stage 1 仍由“rubric + 已确认 anchors + 人工抽审”工作；不得直接脚本写回。
- 只有累计至少 3–4 轮独立 verify、严格一致率达到 75%，且图形题/新定义题/多解题都有稳定规则后，才讨论 Stage 2 强制路由。

当前未满足任一升级条件。

## 6. 工具边界

`tools/difficulty/review_math_g7_bootstrap.py`：

- 输入路径、glob、anchors 和输出路径均由 CLI 提供；没有主工作树或 G6 glob 硬编码。
- 计算时不使用原 `round`；只在输出中记录观察值以便发现全 R1 历史问题。
- 默认不写任何文件；仅在显式传入 `--output` / `--verify-output` 时写报告。
- 每次运行前后计算输入 SHA-256，发现输入发生变化立即报错。
- 不含 batch/index 写回接口。

启发式无法可靠理解图片、证明完整性和隐藏分支；在锚点未确认期间，所有输出均为 `review`。
