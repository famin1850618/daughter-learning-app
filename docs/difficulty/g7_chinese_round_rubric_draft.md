# 七年级语文 Round 路由 Rubric（bootstrap 草案）

状态：`Stage 0 / candidate / 未经 Famin 校准`。本文件只用于候选判断与人工抽审，不授权写回题库。G6 的 rubric 和 anchors 只提供历史信号，不能冒充 G7 标尺。

## 1. 判定对象

Round 衡量“完成七年级对应课程后的学生，在独立完成这道练习时的认知与表达负荷”，不是题号、分值或绝对学术难度。先看解题动作，再看证据跨度、干扰强度和输出约束；题型和字数不能单独定档。

| Round | G7 相对标准 | 典型信号 |
|---|---|---|
| R1 | 直接识记、辨认或原句提取 | 拼音写字、课内名句默写、主题明显的单项归类；闭合答案、一步完成 |
| R2 | 一次规则应用或局部推断 | 词性/敬谦辞/病句辨析、局部指代、短句翻译；通常需比较 2–4 个局部证据 |
| R3 | 跨段、跨文本或跨层次综合 | 文言比较、现代文主旨与作用、材料筛选后表达、名著情节与作用联结；答案需证据链 |
| R4 | 高强度综合、抽象或持续创作 | 全书精神压缩并多处互证、多文本多约束一致性、完整作文的构思—结构—表达联合 |

R4 不是“主观题”，R3 也不是“原文很长”。若材料长但答案可直接摘录，应降档；若题面短却要求全书抽象、分类或持续创作，应检查 R3–R4。

## 2. 四个证据维度

### 2.1 解题动作层级

- 1 层：识记、辨认、抄取。
- 2 层：定位规则或语境，再判断/改写。
- 3 层：筛选多处信息，建立关系，再概括或解释。
- 4 层：提出抽象观点、组织多证据、评价或创作，并保持全文一致。

重复七次同类默写仍可能是 R1；动作层级不因空数机械增加。

### 2.2 证据跨度

- 局部词句：通常 R1–R2。
- 单段到多段：通常 R2–R3，取决于是否需要整合。
- 两篇文言、三则材料、整部名著或全文结构：检查 R3–R4。

“依赖全文”不是自动升档；必须说明哪些分散证据需要联合。

### 2.3 干扰与开放度

- 错项褒贬或对象明显、候选池窄：降档。
- 四项都局部合理、必须逐项核对：升档证据。
- 答案开放但评分点直接给出：不自动升档。
- 答案开放且需自行选择观点、证据和结构并保持一致：检查 R3–R4。

### 2.4 输出约束

- 单字、短词、单句：通常不高于 R2，除非上游推理复杂。
- 分条概括、比较阅读、情境表达：通常 R2–R3。
- 600–900 字完整作文、全书论证、多目标一致性：可进入 R4 候选，但仍需 Famin 决定常规作文是否按 R3 路由。

## 3. 题型保护

### 3.1 字词、语法与默写

- 直接拼写/背诵优先 R1。
- 同形词词性、敬辞谦辞、病句修改等明确规则应用优先 R2。
- 多空只增加执行量，不自动增加思维层级。

### 3.2 现代文与材料阅读

- 直接摘录或单句指代：R1–R2。
- 跨段概括、作用分析、主题论证：R3。
- 全文结构评价、多材料冲突权衡、跨情境迁移且需完整证据链：检查 R4。

### 3.3 文言文、古诗与名著

- 课内名句或固定常识：R1。
- 实词/虚词/单句翻译：R2。
- 比较阅读、意象作用、情节与主题联结：R3。
- 跨全书抽象、多文本互证且无现成路径：R4 候选。

### 3.4 写作

- 短留言、单条仿写、提示充分的局部表达不因“主观”自动超过 R2–R3。
- 完整作文至少要审查取材、结构、主题深化和语言约束。当前样本把完整作文放入 R4 边界池，不代表已经确认；Famin 可把“常规达标作文”统一校准为 R3。

## 4. 组合题统一（强制）

先逐个子题给候选档，再按 `ceil(子题档位平均值)` 得到整组档位；组内每题使用同一候选档。不得选择一个简单子题作为低档 anchor，却忽略同组难题。

候选 anchor 若来自组合题，必须记录：

- `group_id`；
- 全部 `group_member_refs`；
- 子题候选列表；
- `group_unification_status=verified_uniform`。

任何组员缺失、候选混档或平均取整证据缺失，都只能标 `blocked_group_not_unified`，不得回填正式 round。

## 5. Anchor 与阶段规则

1. `g7_chinese_anchor_candidates.json` 中所有条目都是 `requires_famin_confirmation`。
2. G6 anchor 只能帮助发现“直接识记、明显干扰、长材料”等维度，不能作为 G7 最近锚点引用。
3. 生产已有 round 和新 worker 候选只作偏差审计，不能批准 anchor。
4. Famin 确认后，应记录确认档、评语与日期；被改档的候选必须同步修订本 rubric 的边界说明。
5. 每档至少 3 个经确认、跨题型的 G7 anchor，且完成一批未参与选锚题的独立抽审后，才能进入 Stage 1。
6. Stage 2 仍需至少 3–4 轮 verify 且严格一致率达到 75%；本次 bootstrap 不满足。

## 6. 只读工具边界

`tools/difficulty/review_chinese_g7_bootstrap.py` 只读取显式 G7 候选和 anchors：

- 不以生产 `round` 生成候选；
- 不含 batch/index/status 写回接口；
- 组合题候选不统一时直接阻断；
- 所有结果固定为 `review`；
- 运行前后核对输入 SHA-256。
