# G7 数学难度路由 bootstrap 审计

日期：2026-08-11

## 结论

现有 `tools/d2_math_review_v4.py` 不能直接用于七年级数学。它是基于 G6 Famin 反馈迭代出的 V4，并不构成跨年级校准。

## 旧 reviewer 的可移植性问题

- 仓库根目录硬编码为 `/home/faminwsl/daughter_learning_app`。
- 输入硬编码为 `assets/data/batches/realpaper_g6_math_*.json`。
- anchors、V1 日志和输出日志均为固定 G6/本机路径。
- 主要特征围绕 G6 的比例尺、百分数、圆柱圆锥、行程和单位换算；七年级的绝对值分段、整式、方程、新定义、平面几何追角、动点与变量关系覆盖不足。
- 最近锚点文本相似度使用连续中文片段集合，语义分辨率有限。
- 旧脚本输出提示仍称 `V2 reviewer`，版本语义和执行版本不完全一致。
- 它能直接生成待写回档位；在 G7 未建立锚点前，这会制造“脚本看似确定”的错误安全感。

## 本次范围审计

- 10 套七上期末原始候选：199 题，其中救急发布 85 题均暂保留 R1，114 题因结构重构或 G7 难度校准暂缓。
- 既有 G7 数学：`qm_shenzhong_001` 23 题、`qz_yantian_001` 20 题，也存在全 R1 或缺乏 G7 专用校准证据的问题。
- bootstrap 候选池因此覆盖七上基础知识和既有七下/综合题，但尚不代表课程全覆盖。

## 新方案

- 独立 G7 rubric：`g7_math_round_rubric_draft.md`。
- 16 道未确认候选锚点，R1–R4 各 4 道：`g7_math_anchor_candidates.json`。
- read-only reviewer：`tools/difficulty/review_math_g7_bootstrap.py`。
- Famin 抽审稿由 reviewer 从候选 JSON 生成，避免文档与候选数据漂移。

## 明确未完成

- 没有任何 G7 锚点被确认。
- 没有把候选档位写回 85 题、114 题或既有 G7 批次。
- 没有证明当前启发式达到生产准确率。
- 图片依赖候选仍需 Famin 结合原图判断。
- 114 题中的多子题必须先按 `series_combo` 重构，随后才能按“组合题子题先判、组内统一”规则路由。

## 建议的最小人工审定

先审每档 3 题，共 12 题。选择标准是跨知识点、兼顾有图/无图，并覆盖救急 85、暂缓 114 和既有 G7 三类来源。若任一档至少 2 题被改档，则该档剩余候选全部复审，且不得把该档作为 Stage 1 基线。
